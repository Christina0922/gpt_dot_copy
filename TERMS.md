# Use and refunds

Last updated: November 11, 2026

Dot Copy Paste is free to install. Copy and the paste guidance stay free. Exporting a dot conversation is a separate one-time feature priced at KRW 4,900. There is no monthly subscription and no automatic renewal. Buying it does not include every feature that may be added later.

The seller is the extension developer, not Google. The Chrome Web Store developer email is `connect.geniusbrain@gmail.com`.

Version 0.2.5 does not sell this feature. The purchase button says the sale is in preparation and does not open a payment page. Full-thread export is not part of the offer. No refund can be requested for a purchase this version does not accept. A payment-success page does not activate the purchase.

The export file is created in the browser. The full conversation is not confirmed on the live dot page, so a saved file would be labeled as the messages loaded on screen. Original attachments are not downloaded. That file is not uploaded to a license server.

A future connected sale may grant export only after the license server checks a signed payment notification or the payment provider's own transaction record. The product, amount, currency, and buyer account must match. An email address alone is not accepted. A refund or cancellation notice from that provider updates the entitlement. A temporary server failure is not treated as a refund.
